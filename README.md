# Collaboration Demo

A small practice project for learning collaborative development with GitHub.

## Project Feature

This project demonstrates how teams collaborate using issues, branches, pull requests, and code reviews.

## Getting Started

1. Open the repository on GitHub.
2. Review the existing issues.
3. Create a branch for your work.
4. Make your changes and commit them.
5. Open a pull request linked to the related issue.

## Contribution Guidelines

- Create or use an issue to describe the task.
- Make changes on a separate branch.
- Keep commits focused and clear.
- Explain your changes in the pull request.
- Respond to review feedback before merging.

## Pull Request Workflow

1. Open a pull request from your branch into main.
2. Link the related issue using Closes #issue-number.
3. Review the changes and address feedback.
4. Merge the pull request when it is ready.

   This project is maintained as a GitHub collaboration exersice.
